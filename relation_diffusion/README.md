## 为什么值得试

普通 masked diffusion 每轮要预测多个原 token。若同轮 token 彼此依赖，独立采样的边缘概率未必能拼出合理的联合答案。廉价的跨 token 双射可能把一部分依赖转成更容易并行生成的变量，再还原为原文。

真正要验证的是：**在同一模型规模、训练预算、数据和输出长度下，关系模型能否用更少轮次达到原模型的质量，且节省时间超过逆变换成本。**

对于固定、与答案无关的揭示顺序，理想条件边缘对应的路径损失可分解成原始联合熵与各轮条件总相关量之和。神经网络实际损失还要加上拟合误差。相关性下降不保证总损失或任务正确率改善。

## 最大的四个风险

1. **改变模型要学习的语言表示。** 稀疏排列也会改变输入和目标的语义。冻结原 LLaDA 直接输入关系码没有依据，LoRA 是否足够未知。要有使用相同额外训练预算的原 token 对照。
2. **浅层变换表达能力有限。** 附件的整链差分成功例使用前缀扫描逆变换，不能当成一到两层局部条件排列已经成功。自然语言的依赖还可能跨距离、跨多个 BPE token；分组不能借用生成时未知的答案或解析结果。
3. **可逆不保证错误局部。** 正确码能无损恢复；错误锚点可能影响多个还原 token。必须同时测单码错误的影响范围、原文质量和逆变换时间。
4. **现有工作的交叉较密集。** “离散 flow + diffusion base”本身不够成为贡献。需要真实文本上稳定的少步收益，以及对廉价可逆表示适用条件的实证解释。

同长度、同词表的双射只是在重排联合概率，并不能把任意分布都变成独立分布。复制链是适配差分的特例。

## 已实现与本地结果

- `codec.py`：稀疏条件排列、基于训练数据频率的冻结拟合、一到多层可逆组合、保护特殊 token、保持 prompt 前缀；另有逐 token 重编号和整链差分参照。NumPy 参考实现，不是优化后的 GPU 内核。
- `probe.py`：枚举二元序列的真实联合分布，比较固定 1/2/4/12 轮路径的理想 KL、TV、条件总相关量；统计单个关系码错误传播。一步路径同时代表“同一编码 + 无 diffusion 的独立生成器”对照。
- `tests/`：非二元空间的穷举可逆性、排列补全、前缀/特殊 token 保持、固定路径归一化及损失分解、成功例与反例。
- `results/mechanism_seed1234_v2.json`：本地执行产生的原始结果。

2026-09-12 本地验证：`python -m pytest relation_diffusion/tests -q`，**9 passed**；默认长度 12 的完整机制探针执行成功。

长度 12，统计编码只用另外抽取的 8192 个合成训练样本拟合。评估使用完整人口分布和理想条件边缘，**不包含神经网络拟合误差**。

| 编码 | 复制链一步 KL（nats，越低越好） | 一次码翻转最多影响几个原 token |
| --- | ---: | ---: |
| 原 token | 6.142455 | 1 |
| 逐 token 重编号 | 6.142455 | 1 |
| 一层统计关系编码 | 2.792025 | 2 |
| 两层统计关系编码 | 2.792025 | 2 |
| 整链差分参照 | 约 0 | 12 |

第二层在这个案例中没有进一步降低 KL，不能据此推断增加层数总会有效。二元空间内，非平凡的随机条件排列等价于 XOR 或其重编号，可能与统计编码打平；要判断“学习排列”是否有贡献，必须进入更大词表。

在原本独立的 Bernoulli(0.2) 数据上，整链差分反而把一步 KL 从约 0 增加到 **1.391137**。这些结果只能证明机制存在、实现一致，以及不合适的编码会有害；**不是文本能力、5090 速度或训练成功的证据**。

## 决定性实验（工具已接入，真实文本结果待测）

不要继续靠更多异或案例判断研究价值。下一阶段需要真正训练：

1. 用有明确训练/验证划分的真实文本。先用 byte/small-vocabulary 任务排查，再用 BPE 文本验证，不能用数学或代码测试集拟合编码。
2. 同样的小型双向 Transformer、训练 token 数、训练步数、随机种子组和固定揭示路径，分别训练原 token、逐 token 重编号、随机浅层变换、统计浅层变换。记录编码拟合与预处理成本；禁止给关系模型更多训练资源后宣称收益来自编码。
3. 额外比较“相同编码 + 一步独立生成器”，分辨收益来自 flow 还是多步去噪。模型学习误差必须进入评估。
4. 测 2/4/8/16 轮质量—延迟曲线，单独记录正向耗时、逆变换耗时、峰值显存、码错误到原 token 的扩散，以及原始文本单位的固定路径交叉熵和样本质量。
5. 通过以上检查后，再考虑对预训练 dLLM 继续训练，最后上 GSM8K/HumanEval。与冻结 Fast-dLLM 的对比只能作为系统参考，主消融还需要同等训练的原 token 模型。

概率对应回原文依赖双射，但不能因此声称任意自适应、随机去噪过程的完整似然都能廉价精确计算。这里实现的分解仅限明确指定的固定揭示路径。

**继续标准（项目判断，不是已达成结果）：** 在真实文本、多个随机种子和多个少步设置下得到稳定改善，扣除编码成本后仍有质量—延迟优势。可将“关系 4 轮达到原 token 8 轮质量”设为研究目标。

**停止/转向标准：** 只在合成复制数据有效；真实文本拟合误差吞掉依赖收益；依赖昂贵逆向网络；或同等训练的一步 flow 基线已经解释全部改善。

## 相关工作与新颖性边界

- [Discrete Flows (2019)](https://arxiv.org/abs/1905.10347)：离散可逆变换与并行生成已有，不能把耦合层本身作为新方法。
- [ReDi (2025)](https://arxiv.org/abs/2507.15897)：把分解误差与条件总相关量联系起来，并优化源—目标耦合；本方案选择改变目标坐标。
- [MDM-Prime-v2 (2026)](https://arxiv.org/abs/2603.16077)：子 token 编码、粒度与索引选择影响扩散学习；“改编码”本身并不新，跨 token 双射仍需独立验证价值。
- [FLDD (2026)](https://arxiv.org/abs/2605.18204)：学习前向加噪过程以改善少步生成；本方案限制为冻结离散双射后普通遮盖。

这是对公开近邻的可行性审查，不是完整的新颖性排查或发表保证。
